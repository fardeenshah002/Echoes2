# ECHOES - Pro Audio Suite 🎧

A sleek, modern web-based music streaming application inspired by YouTube Music with a distinct Deep Space & Neon aesthetic.

## ✨ Features

- **Dynamic Recommendations**: Automatically updates the "Made for You" section based on your recent listening history stored locally.
- **Instant Search**: Search through millions of global tracks and artists using the iTunes Search API.
- **Mood Chips**: Switch vibes instantly between Workout, Relax, and Pop Hits.
- **Live Synced Lyrics**: Integrated lyrics view with line tracking and auto-scrolling.
- **Custom Playlists**: Create, manage, and store multiple personalized playlists directly in `localStorage`.
- **Full Player & Mini Dock**: Floating mini player with an expandable full-screen player view.
- **Audio Controls**: Shuffle, repeat/loop, interactive scrubber, and responsive playback controls.
- **Mobile Responsive**: Optimized for both desktop and mobile screens.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS, FontAwesome Icons, Google Fonts (Outfit)
- **APIs**: iTunes Search API, Lyrics.ovh API
- **Storage**: Browser LocalStorage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Search for your favorite artist or select a track from the home recommendations to start listening!

## 🌐 Deployment (GitHub Pages)

1. Push `index.html` and `README.md` to the root of your GitHub repository.
2. Go to repository **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live in a few minutes!
