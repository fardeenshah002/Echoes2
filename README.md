# ECHOES - Next-Gen Audio Streaming Platform

ECHOES is a feature-rich, high-performance web audio streaming application built with a dark glassmorphic UI, real-time global song search, liked songs saved in LocalStorage, pro audio equalizer, sleep timer, theme switcher, and synchronized karaoke lyrics view.

## 🚀 Key Features
- 🎵 **Global Song Search**: Real-time track search powered by external audio APIs.
- ❤️ **Playlists & Liked Songs**: Persistent storage using browser LocalStorage.
- 🎛️ **Pro Equalizer & Sleep Timer**: Bass, mid, treble controls and auto-pause sleep timer.
- 🎤 **Live Synced Lyrics**: Karaoke-style dynamic lyric view.
- 🎨 **Theme Switcher**: Multiple neon accent color modes.
- 🎚️ **Audio Spectrum Visualizer**: Dynamic HTML5 Canvas visualizer.
